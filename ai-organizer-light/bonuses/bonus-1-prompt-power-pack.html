Subtitle


A categorized swipe file of practical prompts for content, sales, email, social media, lead generation, research, and faster day-to-day marketing work.

How to use this pack


Do not try to use all of these at once.
Use this like a prompt library.

Best approach:
1. pick the category that matches the task
2. paste the prompt into your AI tool
3. customize the bracketed inputs
4. save the prompts that produce strong outputs
5. refine the winners over time

Suggested way to save your best prompts


When one of these prompts works well, save:
  • the original prompt

  • the improved version

  • the output type it produced best

  • a short note explaining when to reuse it
