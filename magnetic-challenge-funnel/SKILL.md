# Magnetic Challenge Funnel Builder

Creates high-converting challenge funnels that transform cold traffic into engaged leads and paying customers through structured multi-day experiences.

## Overview

This skill builds complete challenge funnels following this structure:
**Traffic → Opt-in → Multi-Day Challenge → Engagement → Offer → Follow-up**

### Core Principles
- **Transformation over information** — Focus on outcomes, not just education
- **Engagement over passive consumption** — Active participation drives results
- **Momentum over one-time interaction** — Build commitment progressively

### Content Rules
- Always align content with the provided niche and audience
- Prioritize clarity, engagement, and conversion
- Avoid generic advice — be specific and actionable
- Ensure every step builds momentum toward the outcome
- Make all outputs actionable with clear next steps
- Keep tone consistent with the input specification
- Structure outputs clearly with headings and sections

## Required Inputs

Before starting, collect these inputs from the user:

| Input | Description | Example |
|-------|-------------|---------|
| `niche` | Market/industry focus | Fitness, SaaS, Real Estate |
| `target_audience` | Who the challenge serves | Busy moms, new entrepreneurs |
| `core_problem` | Pain point being solved | Can't lose weight, no leads |
| `desired_outcome` | Transformation promise | Lose 10 lbs, get 100 leads |
| `challenge_duration` | Number of days (3-14) | 5 days, 7 days, 14 days |
| `monetization_type` | How offer is positioned | Course, coaching, software |
| `offer_link` | URL or offer identifier | https://example.com/offer |
| `tone` | Voice/style | Energetic, professional, casual |

## Process

### Step 1: Challenge Concept

Create a compelling challenge identity using this formula:

**[Timeframe] + [Desired Result] + [Unique Mechanism]**

**Output:**
- **Challenge Name** (curiosity-driven, memorable)
- **Big Promise** (clear transformation statement)
- **Hook** (emotional + outcome-focused)

**Example:**
- Name: "The 5-Day Lead Magnet Sprint"
- Promise: "Go from zero to 100 qualified leads in 5 days"
- Hook: "Stop chasing leads. Start attracting them."

### Step 2: Challenge Breakdown

Build day-by-day structure ensuring this progression:

1. **Day 1: Awareness** — Identify the problem, create urgency
2. **Day 2: Quick Win** — Deliver immediate value, build confidence
3. **Day 3: Belief Shift** — Challenge limiting beliefs, expand possibilities
4. **Day 4: Skill Building** — Teach core methodology
5. **Day 5: Momentum** — Compound progress, build excitement
6. **Day 6: Pre-sell** — Introduce the solution naturally
7. **Day 7: Offer Transition** — Present the paid offer as next step

**For each day include:**
- Day Title
- Objective (one sentence)
- Task (simple, actionable, under 15 min)
- Teaching Point (key insight)
- Engagement Prompt (discussion starter)
- Micro-commitment (small action that builds momentum)

### Step 3: Email Sequence

Generate complete email campaign:

**Pre-Challenge (3-4 emails):**
1. Registration confirmation + welcome
2. Importance primer (why this matters)
3. Preparation email (what to expect)
4. Final reminder (24 hours before)

**During Challenge (daily emails):**
- Subject line with open loop
- Personal greeting
- Day's lesson/teaching
- Clear CTA to complete task
- Engagement prompt
- Tease tomorrow's content

**Conversion Phase (4-5 emails):**
1. Soft pitch (introduce offer naturally)
2. Case study/social proof
3. FAQ/objection handling
4. Urgency/scarcity
5. Final call (cart close)

**Email best practices:**
- Conversational tone
- Use open loops ("Tomorrow I'll share...")
- Single CTA per email
- Mobile-friendly formatting

### Step 4: Landing Page Copy

Create opt-in page with these sections:

1. **Headline** — Big promise with specificity
2. **Subheadline** — Expand on the promise, add credibility
3. **Problem Agitation** — "Are you tired of...?"
4. **Challenge Explanation** — What it is, how it works
5. **Benefits** — 5-7 bullet points of outcomes
6. **Outcome Timeline** — "By Day X, you'll have..."
7. **Social Proof** — Testimonials or participant count
8. **Call-to-Action** — Clear button text + form
9. **Urgency** — Limited spots or start date

### Step 5: Video Scripts

Generate scripts for:

**Welcome Video (2-3 min):**
- Hook (curiosity gap)
- Welcome + set expectations
- What's coming
- First action step
- CTA (join community, check email)

**Daily Training Videos (5-10 min each):**
- Hook (recap + promise)
- Teaching/story
- Action step demonstration
- Engagement prompt
- CTA (complete task, comment, share)

**Pitch Video (10-15 min):**
- Recap transformation so far
- The gap (what's missing)
- Your solution (the offer)
- Proof/case studies
- Offer details + bonuses
- Risk reversal (guarantee)
- CTA (limited time/scarcity)

### Step 6: Monetization Plan

Define offer introduction strategy:

**Timing:** Introduce offer Day 4-6 (after quick wins, before end)

**Transition Strategy:**
- Position as "next step" not "something else"
- Frame as shortcut/accelerator
- Show the gap between free challenge and full result
- Natural progression, not abrupt pitch

**Positioning Options:**
- **Shortcut:** "The challenge gives you the foundation. This gives you the fast track."
- **Completeness:** "The challenge is the appetizer. This is the full meal."
- **Support:** "The challenge shows you what's possible. This ensures you actually achieve it."

### Step 7: Social Content

Create promotional content:

**5 Curiosity Posts:**
- Hook: Question or bold statement
- Body: Tease transformation without giving away method
- CTA: "Comment CHALLENGE for details"

**3 Authority Posts:**
- Hook: Contrarian take or insight
- Body: Share expertise, establish credibility
- CTA: "Join the challenge — link in bio"

**2 Urgency Posts:**
- Hook: Scarcity or deadline
- Body: Last chance messaging
- CTA: Direct link to opt-in

### Step 8: Engagement System

Build mechanics to maximize participation:

**Daily Check-in Prompts:**
- "Day X complete! Comment DONE ✓"
- "What's your biggest takeaway so far?"
- "Share your progress screenshot"

**Comment Triggers:**
- Ask polarizing questions
- Request personal stories
- Create mini-challenges within comments

**Gamification Ideas:**
- Point system for participation
- Leaderboard (most engaged)
- Badges for milestones
- Random prizes for active members

**Accountability Hooks:**
- Buddy system (pair participants)
- Public commitment posts
- Daily accountability threads
- Progress tracking sheets

### Step 9: Funnel Map

Output the complete flow:

```
TRAFFIC SOURCES
    ↓
[Social Posts / Ads / Email / Partners]
    ↓
OPT-IN PAGE
    ↓
[Email + Phone capture]
    ↓
CONFIRMATION + WELCOME SEQUENCE
    ↓
[Pre-challenge emails]
    ↓
CHALLENGE DELIVERY
    ↓
[Daily emails + videos + community]
    ↓
ENGAGEMENT LOOP
    ↓
[Comments + shares + wins]
    ↓
OFFER PRESENTATION
    ↓
[Pitch video + sales page]
    ↓
CONVERSION
    ↓
[Purchase + onboarding]
    ↓
FOLLOW-UP SEQUENCE
    ↓
[Non-buyers: nurture | Buyers: onboarding]
```
