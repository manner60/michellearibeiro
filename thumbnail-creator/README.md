# 🎨 Michelle's AI Thumbnail Creator

Your personal, AI-powered thumbnail creation tool. Built just for you - no outsourcing needed.

## ✨ Features

- **🎨 Visual Editor**: Drag-and-drop canvas with real-time preview
- **🤖 AI Generation**: Smart template generation based on text prompts
- **📐 Multiple Formats**: YouTube, YouTube Shorts, Instagram, TikTok
- **🎯 Templates**: Pre-built templates for quick starts
- **🖼️ Image Upload**: Add your own images
- **🔤 Custom Fonts**: Oswald, Bebas Neue, Inter, Roboto Condensed
- **🎨 Color Gradients**: Beautiful pre-made gradients + solid colors
- **📱 Responsive**: Works on desktop and tablet

## 🚀 Quick Start

1. Open `index.html` in your browser
2. Choose a template or start blank
3. Add text, images, shapes
4. Customize colors and fonts
5. Download your thumbnail

## 🎯 Templates Included

- **Blank**: Start from scratch
- **Gradient**: Beautiful gradient backgrounds
- **Bold Text**: High-impact text-focused design
- **Split**: Before/After comparison style
- **Minimal**: Clean and simple
- **Vibrant**: Eye-catching colorful designs

## ⌨️ Keyboard Shortcuts

- `Ctrl+S`: Download thumbnail
- `Delete`: Remove selected layer
- `Double-click`: Edit text layer

## 🤖 AI Generation

Describe what you want (e.g., "A vibrant tech review thumbnail with neon blue background") and the AI will:
- Select appropriate colors
- Position text optimally
- Add decorative elements
- Create a professional design
